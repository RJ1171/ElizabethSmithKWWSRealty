# Assistant Notes

This repository contains a simple static HTML/CSS/JS QR landing page for Elizabeth Smith and the Willis & Smith Group.

## Site Type

- Static website
- No framework
- No build dependency
- No local server required for deployment

## Entry Point

The public page entry point is:

```text
index.html
```

## Deployment

Deploy on Vercel with:

- Framework Preset: `Other`
- Build Command: leave empty
- Output Directory: leave empty
- Root Directory: `.`

## Important Files

- `index.html` - landing page markup
- `styles.css` - responsive mobile-first styling
- `script.js` - sticky contact CTA behavior
- `assets/` - image assets used by the landing page
- `vercel.json` - static hosting/cache headers
- `docs.json` - minimal metadata file for hosting/template compatibility

Do not add framework build tooling unless the project is intentionally converted away from a static site.
